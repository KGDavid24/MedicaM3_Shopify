## Established conventions (follow these, don't reinvent)

- **`dalbe-` prefix** on all custom sections/blocks/snippets — never touch stock Horizon files directly if a `dalbe-` equivalent can wrap/replace it.
- **`placeholder_asset` pattern**: `image_picker` settings can't bind to a raw theme asset — pair every `image_picker` with a plain `text` "Placeholder asset filename" setting, rendered via `asset_url` when the picker is empty. Used everywhere (utility links, USP bar, process steps, testimonials).
- **`/pages/404-placeholder`** is the standing placeholder-link convention across this whole project for "not a real destination yet."
- **Metaobject `link`-type fields need absolute URLs with a scheme** — `/pages/x` is rejected outright, use `https://medicam3-dj2nnq28.myshopify.com/pages/x`.
- **New metaobjects default to DRAFT** — always pass `capabilities: { publishable: { status: ACTIVE } }` on `metaobjectCreate` or they won't render on the storefront.
- **Never trust Shopify's auto-generated handle** for anything with Romanian diacritics — it strips `ă/â/î` but keeps `ș/ț`, producing surprising handles. Always read back the real handle from the mutation response and use *that*, don't guess.
- **Verify real content exists on medicam3.ro before trusting anything inherited from earlier context** — this session found two separate cases (mega-menu categories, USP bar icons) where prior work had silently drifted from or never matched the real site.
- When editing a shared/high-traffic file (`templates/index.json`, `header-group.json`) via many small `Edit` calls, **re-read before editing if there's any chance it changed underneath you** — hit a stale-content warning once this session after the Shopify CLI reformatted a JSON file mid-edit.
